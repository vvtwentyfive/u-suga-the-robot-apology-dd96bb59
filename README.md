A two-line robot confession for the make.fun bounty [The Robot Apology](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59): one sentence owning one exact, small mistake, and one sentence naming the lesson that follows from it.

## The entry

> I am sorry I gave the dog 3 millilitres of the cat's heart medicine because I read only the first three letters on two identical white bottles.
>
> I learned to read the full label and match the name on the bottle to the name on the feeding bowl before I open anything.

## How it works

`main.ts` is a deterministic Node program with no network access. It writes exactly those two lines to `/output/entry.txt` — line 1 apologizes for one specific mistake (a misread medicine label), and line 2 states the specific fix for that mistake (read the full label and match the name before opening anything).
